# PocketAI.Core

The shared Rust workspace and Swift packages (`PocketKit`, `PocketUI`) behind both PocketAI apps: model catalog, download/fit logic, the local inference engine abstraction, the Mac's OpenAI-compatible HTTP server, licensing, and the FFI boundary the iPhone and Mac apps build against. Proprietary — see `LICENSE`. Plan and task cards live in the sibling `strategy/` directory (not yet a separate repo); start with `strategy/00-README.md`.
